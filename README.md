# Cartão × Pix

PWA mobile-first para comparar pagamento no cartão x Pix.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `manifest.webmanifest` e `sw.js` para a raiz.
3. Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/root`.
4. Abra a URL gerada no iPhone.
5. No Safari: Compartilhar → Adicionar à Tela de Início.

A calculadora não pede seleção de cartão/programa: testa automaticamente Elo Nanquim e Itaú Black contra Azul, Smiles e LATAM Pass.
